安裝與運行步驟 (Installation)

複製專案 (Clone the repository)

git clone https://github.com/DDan32/VeloDice.git


進入專案目錄 (Navigate to directory)

cd VeloDice


安裝依賴套件 (Install dependencies)

# 若為 iOS / Pod
pod install

# 若為跨平台 JS 框架
npm install


啟動應用程式 (Run the app)

打開 VeloDice.xcworkspace 或透過您的 IDE 點擊運行 (Run) 按鈕。
